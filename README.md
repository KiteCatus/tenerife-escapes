# Tenerife Escapes

## Om sidan
Vad handlar sidan om, och vem är den till för? Två–tre meningar.
Tenerife Escapes hjälper användaren med att skapa en resa utan att vara stressad och trött. De kan bara slappna av eftersom företaget ska lösa problemet. Det är till för människor som är tröttna med planering och vill bara slappna av med att kontakt företaget via webbsidan och berättar vad de vill.
